# CodeAlpha Frontend Development Tasks

Three tasks completed for the CodeAlpha Frontend Development internship.

| Task | Folder | What it has |
|------|--------|-------------|
| Calculator | `calculator/` | + − × ÷, clear, delete, %, keyboard support |

| Portfolio | `portfolio/` | About, Skills, Projects, Resume, Contact, smooth scroll, animations |
